# NEAR Hackathon submission checklist

- [ ] Mainnet NEAR account for potential prize receipt
- [x] Public GitHub repository: https://github.com/victorkay97/RecallBond
- [ ] Passing Rust unit tests and WASM build
- [ ] Passing NEAR sandbox integration tests
- [ ] Deployed testnet smart contract and documented transaction hashes
- [ ] Web interface connected to actual NEAR contract
- [ ] Reproducible README with command/expected-output steps
- [ ] No secrets in repository or Git history
- [ ] Public demo on X mentioning NEAR Hackathon, tagging @NEARProtocol and #NEARHackathon
- [ ] Submit repository and public X demo through official form before Nov 14 2026, 23:59 UTC
- [ ] Select the applicable track(s): primary NFTs That Do Something

If a second independent project is also submitted by the same participant, the official FAQ requires each README to name the other project.
